# Workspace setup

Set up the identity and operating boundaries before inviting a large team.

## Business profile

Settings contains the business or institution name, legal name, contact information, timezone, currency, invoice prefix, industry, and tax configuration. Industry changes use a reviewed request because changing industry alters terminology and available modules.

## Locations

Locations scope schedules, stock, invoices, staff access, and operational reporting where those concepts apply. Mark one active location as primary and use stable location codes for integrations.

## Team and access

Invite each person with their own account. Do not share owner credentials. Assign roles according to responsibility, then narrow access by location, department, program, batch, or cohort when supported.

## Recommended rollout

- Begin with one location or one placement cohort.
- Import a representative data set and review validation errors.
- Verify dashboards against source records.
- Test permissions with a non-owner role.
- Expand only after the first workflow is reliable.
